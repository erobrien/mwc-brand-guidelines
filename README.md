# Men's Wellness Centers Brand Guidelines

The current brand guideline for Men's Wellness Centers, built from the live website at https://menswellnesscenters.com. The logo comes from https://mwcbrand.com/logo. All other mwcbrand.com color, font and voice guidance is replaced by this repo.

| File | Use |
| --- | --- |
| [mwc-brand-guidelines.md](mwc-brand-guidelines.md) | Full guideline for people and AI tools |
| [brand.json](brand.json) | Machine-readable design tokens and copy rules |
| [llms.txt](llms.txt) | Short summary for LLMs and AI assistants |
